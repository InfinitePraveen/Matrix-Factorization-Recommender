# Contributing

Thanks for taking an interest in this project.

## Simple workflow

1. Fork the repository.
2. Create a branch for your change.
3. Keep changes focused and easy to review.
4. Test the notebook from a clean environment when practical.
5. Test the Flask application locally.
6. Update `CHANGELOG.md` when your change affects users.
7. Open a pull request with a clear description.

## Project guidelines

- Keep the repository lightweight.
- Do not add a `src/` directory.
- Avoid unnecessary preprocessing or helper modules.
- Prefer clear notebook code for experimentation and learning.
- Keep the Flask application simple and readable.
- Do not commit large raw datasets or unnecessary generated files.
