# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-09-24

### Added

- MovieLens small dataset download through the notebook.
- SVD collaborative filtering model using Surprise.
- RMSE and MAE evaluation.
- User-specific movie recommendations.
- CPU-friendly notebook workflow.
- Flask web application.
- GitHub and LinkedIn profile links in the web app.
- Model and metadata persistence with Joblib and CSV.
- CONTRIBUTING.md and project documentation.
